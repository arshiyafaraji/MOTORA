# قالب سایت موتورسیکلت MOTORA

## ساختار فایل‌ها
تمام فایل‌ها در ریشه Repository قرار می‌گیرند و پوشه assets وجود ندارد:

- `index.html`
- `style.css`
- `script.js`
- `logo.png` لوگوی سایت
- `HEADER.png` تصویر پس‌زمینه هدر اصلی

## قرار دادن تصاویر
دو فایل PNG را کنار `index.html` قرار دهید و نام آن‌ها را دقیقاً `Logo.png` و `HEADER.png` بگذارید.

## اجرای محلی
فایل `index.html` را در مرورگر باز کنید یا از Live Server در VS Code استفاده کنید.

## انتشار در GitHub Pages
1. فایل‌های بالا را در ریشه یک Repository آپلود کنید.
2. وارد Settings > Pages شوید.
3. در بخش Build and deployment، گزینه Deploy from a branch را انتخاب کنید.
4. شاخه `main` و پوشه `/ (root)` را انتخاب و Save کنید.

این نسخه فقط HTML/CSS/JS است و با GitHub Pages سازگار است. GitHub Pages از PHP و MySQL پشتیبانی نمی‌کند.
